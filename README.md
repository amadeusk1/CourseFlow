# D2L Tracker

A Chrome extension for University of Calgary D2L. It collects deadlines from D2L and course outline PDFs, shows them on a calendar, and downloads an ics file.

## Use

1. Open Chrome extensions and turn on developer mode.
2. Load this folder as an unpacked extension.
3. Log into D2L, then open D2L Tracker and scan your courses.
4. Review the calendar and download the ics file.
